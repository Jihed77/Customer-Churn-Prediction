# Customer Churn Prediction 📊

Ce projet vise à prédire l'attrition (Churn) des clients d'une entreprise de télécommunications en utilisant le Machine Learning.

## 📋 Description
- **Analyse Exploratoire (EDA)** : Visualisation des distributions et corrélations.
- **Prétraitement** : Nettoyage, Feature Engineering, Label Encoding.
- **Déséquilibre** : Utilisation de **SMOTE** (Synthetic Minority Over-sampling Technique).
- **Modélisation** : Comparaison de Decision Tree, Random Forest et **XGBoost**.
- **Optimisation** : Cross-validation avec `StratifiedKFold`.

## 🛠️ Technologies utilisées
- Python 3.10+
- Pandas, NumPy, Scikit-learn, XGBoost, Imbalanced-learn, Seaborn.
